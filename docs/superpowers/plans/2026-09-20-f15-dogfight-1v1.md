# F-15 vs F-15 Dogfight (1v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two F-15s, each a real FlightGear instance with a real FDM and real `fox2.nas`, fight a 1v1 dogfight: both flown by the same scripted combat AI, firing real AIM-9s, defeating them with flares, and dying properly with an explosion and a ballistic fall.

**Architecture:** Two FlightGear AppImage instances linked by peer-to-peer `--multiplay` on localhost, so each sees the other as an MP contact (which makes radar, seeker lock, real missile guidance and flare seduction all work as shipped). One Python process drives both through two `NativeBridge` UDP hot loops plus one `Telnet` each for setup. Combat policy lives in one pure-logic `CombatPilot` class instantiated twice.

**Tech Stack:** Python 3 (stdlib socket/struct only for the sim link), pytest, FlightGear 2024.1.7 AppImage, F-15 add-on Nasal (`awg_9.nas`, `fox2.nas`, `weapons.nas`), bash launcher.

**Spec:** `docs/superpowers/specs/2026-09-20-f15-dogfight-design.md`

## Global Constraints

- **Scope is 1v1 only.** Multi-ship, the connectome, chaff, fox3 missiles and granular damage are explicitly out of scope.
- **Never zero-fill `FGNetCtrls`.** Every field is applied every packet. Use `encode_ctrls`/`send_controls` only.
- **`run nasal script=` over telnet is space-delimited** — anything after the first space is silently discarded. Use `f15_props._nasal()`, which asserts this.
- **Do not trust `controls/armament/trigger`** on this airframe. Gun is `fdm/jsbsim/fcs/guntrigger`.
- **Do not disengage `att-hold`.** Clear `/autopilot/locks/{altitude,heading}` *after* `att-hold=1`, with a retry — `startup()` already does this.
- **A setup-only phase still needs someone flying the jet.** `startup()` ends by calling `connect_stick()`, which hands the stick to us; with no control loop running the jet glides into terrain.
- **`elev_surface` (FDM index 89) reads 0.00 always** on this add-on. Use `alpha`/`theta`/`pitchrate`.
- **The live aircraft directory is** `~/.fgfs/Aircraft/org.flightgear.fgaddon.stable_2024/Aircraft/F-15`, not `~/.fgfs/Aircraft/F-15`. Both exist.
- **Existing calibration is fixed, not re-tuned:** `G_TABLE_G`/`G_TABLE_ELEV` inversion for pitch, `CAS_ROLL_RATE_FULL_DPS = 213.1` for roll rate, `STALL_SPEED_KT = 180.0`, `n_max = (V/Vs)²`.
- **Framerate matters:** `fox2.nas:39` warns missile guidance degrades below ~25fps. Record achieved fps with every engagement result.
- Tests are pytest, in `tests/`, plain functions, no fixtures unless needed — match the existing style in `tests/test_brain.py`.

```python
cat > scripts/mp_probe.py <<'EOF'
"""Phase 0: answer the four unknowns the dogfight design rests on.

Nothing in the combat code gets written until these are measured. Session 6
burned real time building on an unverified assumption (FG_HOME/AI being
searched, which it is not), so each of these is a measurement, not a guess:

  1. do two instances see each other as MP contacts?
  2. which sim/multiplay/generic/int[N] carries the flare counter?
  3. where does a fox2 impact report land -- shooter, victim, or both?
  4. what framerate do we actually get with two instances?

Prints findings as "FINDING: key=value" lines so they can be grepped.
"""
import sys
import time

sys.path.insert(0, "scripts")
sys.path.insert(0, "src")
import f15_props as fp
from f15_intercept import Telnet, startup

BLUE, RED = 5501, 5601


def finding(key, value):
    print("FINDING: %s=%s" % (key, value), flush=True)


def mp_contacts(t):
    """Callsigns this instance sees as multiplayer contacts."""
    out = []
    i = 0
    while True:
        cs = t.get("/ai/models/multiplayer[%d]/callsign" % i)
        if cs is None:
            break
        out.append(cs)
        i += 1
    return out


blue = Telnet(port=BLUE)
red = Telnet(port=RED)
time.sleep(2)

# Engines on both, and hand each jet back to its own autopilot: startup()
# clears the FCS locks so our stick reaches the FCS, which leaves nobody
# piloting during a setup-only run.
for name, t in (("BLUE", blue), ("RED", red)):
    print("=== %s startup" % name, flush=True)
    startup(t)
    alt = t.get("/position/altitude-ft")
    t.set("/autopilot/settings/target-altitude-ft", alt)
    t.set("/autopilot/settings/true-heading-deg",
          round(float(t.get("/orientation/heading-deg")), 1))
    t.set("/autopilot/locks/altitude", "altitude-hold")
    t.set("/autopilot/locks/heading", "true-heading-hold")

# --- 1. MP contact visibility (gates everything)
for _ in range(15):
    b, r = mp_contacts(blue), mp_contacts(red)
    if b and r:
        break
    time.sleep(2)
finding("blue_sees", b)
finding("red_sees", r)
if not (b and r):
    print("FATAL: instances do not see each other over MP. STOP.", flush=True)
    sys.exit(1)

# --- 4. framerate, against fox2.nas:39's ~25fps guidance threshold
for name, t in (("blue", blue), ("red", red)):
    finding("%s_fps" % name, t.get("/sim/frame-rate"))

# --- 2. which generic int carries flares
for name, t in (("blue", blue), ("red", red)):
    vals = [t.get("/sim/multiplay/generic/int[%d]" % i) for i in range(20)]
    finding("%s_generic_ints" % name, vals)
blue.set("/sim/probe/fl", "-")
fp._nasal(blue, 'setprop("/sim/probe/fl",""~armament.flareNode);')
time.sleep(0.4)
finding("blue_flareNode_symbol", blue.get("/sim/probe/fl"))

# --- 3. impact report location: fire one AIM-9 at the MP contact
node = "/ai/models/multiplayer[0]"
fp.arm_aim9(blue)
fp.designate(blue, r if isinstance(r, str) else "RED1")
time.sleep(3)
print("  blue seeker status=%r contact=%s"
      % (fp.missile_status(blue), fp.contact_info(blue)), flush=True)
blue.nasal('if(aircraft.Current_srm!=nil){aircraft.Current_srm.status=0;'
           'aircraft.Current_srm.search();}')
time.sleep(2)
if fp.missile_status(blue) == str(fp.MISSILE_LOCK):
    blue.nasal('aircraft.Current_srm.release();')
    finding("blue_fired", "yes")
    for k in range(20):
        for who, t in (("blue", blue), ("red", red)):
            imp = t._send("ls /ai/models")
            if "impact" in imp:
                finding("%s_impact_tree" % who,
                        [l for l in imp.splitlines() if "impact" in l])
        time.sleep(1)
else:
    finding("blue_fired", "no -- never locked")

blue.close()
red.close()
EOF
```

```python
"""Great-circle geometry, shared by the flight scripts and the combat logic.

Moved out of scripts/f15_intercept.py so src/fly_brain/combat.py can use it
without importing a script that opens sockets -- the combat policy must stay
testable with no FlightGear anywhere in the picture.
"""
import math


def haversine_m(lat1, lon1, lat2, lon2):
    R = 6371000.0
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dphi = math.radians(lat2 - lat1)
    dlambda = math.radians(lon2 - lon1)
    a = math.sin(dphi / 2) ** 2 + math.cos(p1) * math.cos(p2) * math.sin(dlambda / 2) ** 2
    return 2 * R * math.asin(math.sqrt(a))


def bearing_deg(lat1, lon1, lat2, lon2):
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dlambda = math.radians(lon2 - lon1)
    y = math.sin(dlambda) * math.cos(p2)
    x = math.cos(p1) * math.sin(p2) - math.sin(p1) * math.cos(p2) * math.cos(dlambda)
    return (math.degrees(math.atan2(y, x)) + 360.0) % 360.0


def angle_diff_deg(a, b):
    return (a - b + 180.0) % 360.0 - 180.0


def offset_point(lat, lon, heading_deg, dist_m):
    R = 6371000.0
    brg = math.radians(heading_deg)
    p1 = math.radians(lat)
    l1 = math.radians(lon)
    dr = dist_m / R
    p2 = math.asin(math.sin(p1) * math.cos(dr) + math.cos(p1) * math.sin(dr) * math.cos(brg))
    l2 = l1 + math.atan2(math.sin(brg) * math.sin(dr) * math.cos(p1),
                         math.cos(dr) - math.sin(p1) * math.sin(p2))
    return math.degrees(p2), math.degrees(l2)
EOF
```

```python
"""Combat policy for the F-15 dogfight: pure decisions, no FlightGear.

Deliberately importable and testable with no sim running. The arena
(scripts/dogfight.py) owns every socket and property write; this module only
answers "where do I point, how fast do I want to be, and may I shoot".

Output convention matches the calibrated decode layer the project already
has, and the one the connectome must eventually drive: a g-demand and a
roll-rate demand, never raw surface deflections.
"""
import math

from fly_brain.geo import angle_diff_deg, bearing_deg, haversine_m, offset_point

KT_TO_MS = 0.5144

# AIM-9 envelope, from the F-15 add-on's own fox2.nas parameters.
AIM9_MIN_NM = 0.2       # below this the warhead has no time to arm
AIM9_MAX_NM = 9.0
AIM9_FOV_DEG = 27.5     # seeker field of view
AIM9_MIN_TGT_KT = 15.0  # fox2.nas refuses a class-A target slower than this
# Gun: M61A1. Short range, and it only hits with the pipper genuinely on.
GUN_MAX_NM = 0.6
GUN_FOV_DEG = 2.5
# Max instantaneous turn rate is at corner speed; slower and there is not
# enough lift to pull g, faster and the turn radius blows up.
CORNER_SPEED_KT = 430.0


def lead_bearing_deg(own_lat, own_lon, own_speed_kt,
                     tgt_lat, tgt_lon, tgt_heading_deg, tgt_speed_kt):
    """Bearing to where the target WILL be, not where it is.

    Pure pursuit (pointing at the target's current position) is right for a
    fixed waypoint and wrong for a dogfight: against a maneuvering jet it
    degenerates into a lag chase that never closes. Estimate time-to-go from
    present range and own speed, advance the target along its own velocity
    vector, and aim there. One iteration is enough at dogfight ranges.
    """
    rng_m = haversine_m(own_lat, own_lon, tgt_lat, tgt_lon)
    own_ms = max(1.0, own_speed_kt * KT_TO_MS)
    t_go = rng_m / own_ms
    lead_lat, lead_lon = offset_point(tgt_lat, tgt_lon, tgt_heading_deg,
                                     tgt_speed_kt * KT_TO_MS * t_go)
    return bearing_deg(own_lat, own_lon, lead_lat, lead_lon)


def corner_throttle(airspeed_kt, corner_kt=CORNER_SPEED_KT):
    """Throttle that drives airspeed toward corner speed.

    Proportional, clamped to a valid throttle. Being fast is not free in a
    turning fight: above corner the radius grows and the fight is lost by
    geometry rather than by energy.
    """
    err = corner_kt - airspeed_kt
    return max(0.0, min(1.0, 0.55 + err / 300.0))


def aim9_in_envelope(range_nm, bearing_err_deg, target_speed_kt, has_lock):
    """Whether firing an AIM-9 now is legitimate.

    Without explicit discipline an AI empties its rails at zero range and
    nothing ever hits: every one of these conditions is a real launch
    precondition in weapons.nas/fox2.nas, not a heuristic.
    """
    return (has_lock
            and AIM9_MIN_NM <= range_nm <= AIM9_MAX_NM
            and abs(bearing_err_deg) <= AIM9_FOV_DEG
            and target_speed_kt >= AIM9_MIN_TGT_KT)


def gun_in_envelope(range_nm, bearing_err_deg):
    """Whether the gun solution is real. For the endgame inside the AIM-9's
    minimum arming range, where a missile is useless."""
    return range_nm <= GUN_MAX_NM and abs(bearing_err_deg) <= GUN_FOV_DEG


def is_lethal(miss_distance_m, lethal_radius_m=12.0):
    """Did a detonation at this miss distance kill the target.

    FlightGear reports the hit; it has no damage model, so the consequence is
    ours. 12m is an AIM-9-scale fragmentation radius.
    """
    return miss_distance_m <= lethal_radius_m
```

```python
from collections import namedtuple

Command = namedtuple("Command", "g_cmd roll_rate_dps throttle "
                                "fire_missile fire_gun flares state")

STALL_SPEED_KT = 180.0          # 1g stall speed; n_max = (V/Vs)^2
CAS_ROLL_RATE_FULL_DPS = 213.1  # aileron=1.0 commands this via the roll CAS
MAX_G = 9.0
ENGAGE_RANGE_NM = 5.0
K_BANK_TO_RATE = 2.5            # bank error -> commanded roll rate
MAX_BANK_DEG = 80.0


class CombatPilot:
    """One dogfight policy, flown by BOTH jets.

    Instantiated twice with different aggression, so the enemy is exactly as
    capable as we are and there is only one controller to debug.

    Emits a g-demand and a roll-rate demand -- never surface deflections --
    because that is what this airframe's CAS actually accepts, and what the
    connectome would eventually have to produce in its place.
    """

    def __init__(self, aggression=1.0, callsign=""):
        self.aggression = aggression
        self.callsign = callsign
        self.state = "SEARCH"
        self.flares_used = 0
        self.missiles_fired = 0

    def g_available(self, airspeed_kt):
        """Real aerodynamic limit: stall speed scales as sqrt(n)."""
        return max(1.0, (airspeed_kt / STALL_SPEED_KT) ** 2)

    def _roll_to(self, desired_bank_deg, roll_deg):
        bank = max(-MAX_BANK_DEG, min(MAX_BANK_DEG, desired_bank_deg))
        rate = K_BANK_TO_RATE * angle_diff_deg(bank, roll_deg)
        return max(-CAS_ROLL_RATE_FULL_DPS, min(CAS_ROLL_RATE_FULL_DPS, rate))

    def step(self, telem, threat):
        aim = lead_bearing_deg(telem["lat"], telem["lon"], telem["airspeed_kt"],
                               telem["tgt_lat"], telem["tgt_lon"],
                               telem["tgt_heading_deg"], telem["tgt_speed_kt"])
        bearing_err = angle_diff_deg(aim, telem["heading_deg"])
        rng = telem["tgt_range_nm"]
        avail = self.g_available(telem["airspeed_kt"])

        # EVADE first: a missile in the air outranks any shot we might take.
        if threat.get("missile_inbound"):
            self.state = "EVADE"
            # Break INTO the threat so the missile has to pull lead and bleed
            # energy, and put it toward the 3/9 line.
            brg = threat.get("missile_bearing_deg")
            if brg is None:
                brg = bearing_err
            desired_bank = MAX_BANK_DEG if brg >= 0 else -MAX_BANK_DEG
            self.flares_used += 1
            return Command(
                g_cmd=min(avail, MAX_G),
                roll_rate_dps=self._roll_to(desired_bank, telem["roll_deg"]),
                throttle=1.0,
                fire_missile=False,
                fire_gun=False,
                flares=1,
                state=self.state,
            )

        self.state = "ENGAGE" if rng <= ENGAGE_RANGE_NM else "INTERCEPT"

        # Turn hard enough to point at the lead solution, no harder.
        desired_bank = max(-MAX_BANK_DEG,
                           min(MAX_BANK_DEG, bearing_err * 2.0 * self.aggression))
        # A level turn at bank phi needs n = 1/cos(phi) just to hold altitude.
        level_turn_g = 1.0 / max(0.2, math.cos(math.radians(telem["roll_deg"])))
        g_cmd = min(min(avail, MAX_G), level_turn_g * self.aggression)
        g_cmd = max(0.3, g_cmd)

        shoot_missile = aim9_in_envelope(rng, bearing_err,
                                         telem["tgt_speed_kt"], telem["has_lock"])
        shoot_gun = gun_in_envelope(rng, bearing_err)
        if shoot_missile:
            self.missiles_fired += 1

        return Command(
            g_cmd=g_cmd,
            roll_rate_dps=self._roll_to(desired_bank, telem["roll_deg"]),
            throttle=corner_throttle(telem["airspeed_kt"]),
            fire_missile=shoot_missile,
            fire_gun=shoot_gun,
            flares=0,
            state=self.state,
        )
```

```python
"""FlightGear-side wiring specific to the dogfight, on top of f15_props.

Everything here is parameterised by a Telnet handle, so the same functions
drive either instance.
"""
import time

import f15_props as fp

# controls/armament/trigger does NOT work on this airframe -- recorded
# landmine. The gun is JSBSim's own trigger.
GUN_TRIGGER = "/fdm/jsbsim/fcs/guntrigger"


def mp_contact_node(t, callsign):
    """Property node of a multiplayer contact, by callsign.

    MP contacts live under /ai/models/multiplayer[N], NOT aircraft[N]. Note
    Telnet.get() returns None for a property that does not exist, which is
    what makes this index walk terminate.
    """
    i = 0
    while True:
        cs = t.get("/ai/models/multiplayer[%d]/callsign" % i)
        if cs is None:
            return None
        if cs == callsign:
            return "/ai/models/multiplayer[%d]" % i
        i += 1


def arm(t):
    """Everything needed before a shot is even possible.

    arm_aim9 sets the missile model path (fox2.nas never sets it itself, so
    the round is otherwise invisible), loads the four stations, master arm and
    selector. The radar range scale must also be explicit: unset means
    effectively zero, not unlimited, which hides every target.
    """
    fp.arm_aim9(t)
    t.set(fp.RADAR_SERVICEABLE, 1)
    t.set(fp.RADAR_STANDBY, 0)
    t.set(fp.RADAR_DISPLAY, "true")
    t.set(fp.RADAR_RANGE, 40)
    t.set(GUN_TRIGGER, 0)
    time.sleep(0.5)


def seek(t, callsign):
    """Designate by callsign and start the seeker. True once locked.

    armament.contact cannot be set directly -- awg_9's rdr_loop nils it every
    frame unless the radar is on and displayed. Designating by callsign lets
    az_scan re-assert it on every scan instead.
    """
    fp.designate(t, callsign)
    t.nasal('if(aircraft.Current_srm!=nil){aircraft.Current_srm.status=0;'
            'aircraft.Current_srm.search();}')
    time.sleep(0.5)
    return fp.missile_status(t) == str(fp.MISSILE_LOCK)


def fire_missile(t):
    """Release the selected AIM-9. True if a round actually left the rail.

    Verified by RESULT: a release that silently no-ops (no lock, empty
    station, outside the launch zone) is otherwise indistinguishable from a
    launch. A launched missile appears in /models/model[N] via the model
    manager, NOT in /ai/models.
    """
    before = _airborne_aim9(t)
    t.nasal('aircraft.Current_srm.release();')
    time.sleep(1.0)
    return _airborne_aim9(t) > before


def _airborne_aim9(t):
    n = found = 0
    while True:
        path = t.get("/models/model[%d]/path" % n)
        if path is None:
            return found
        if "aim-9" in path.lower():
            found += 1
        n += 1


def fire_gun(t, on):
    t.set(GUN_TRIGGER, 1 if on else 0)
```

```python
EXPLOSION_MODEL = ("/home/nikhil/.fgfs/Aircraft/org.flightgear.fgaddon"

                   "explosion-0.xml")


def explode(t, lat, lon, alt_ft):
    """Put an explosion at a point. FlightGear reports hits but models no
    damage, so the visible consequence is ours to supply.

    geo.put_model takes METRES, not an "elevation-ft" key -- the wrong
    unit/key has crashed FlightGear outright mid-placement before.
    """
    alt_m = alt_ft * 0.3048
    fp._nasal(t, 'geo.put_model("%s",%.6f,%.6f,%.1f);'
                 % (EXPLOSION_MODEL, lat, lon, alt_m))


def kill(t):
    """Make a killed jet fall out of the sky instead of vanishing.

    Cut both engines and centre the surfaces; the arena stops sending control
    packets for a dead jet, so it goes ballistic and strikes terrain.
    """
    fp._nasal(t, 'setprop("/controls/engines/engine[0]/cutoff",1);'
                 'setprop("/controls/engines/engine[1]/cutoff",1);')
EOF
```

```python
    cur = t.get(FLARE_PROP)
```
